## 变更

- 媒体库卡片悬停由直接放大改为指针跟随的 3D 按压效果，并增加环绕阴影；开启“减弱动态效果”时自动使用静态反馈。
- 放大并重新裁切全套 macOS 应用图标，使 Dock、访达和 DMG 安装后的图标尽量铺满，不再出现灰白色外围背景。
- 重整项目使用说明，补充安装、快速开始、下载目录、后台运行、资源占用、隐私和常见问题。

## 修复

- 修复在本地开发版、旧版与 GitHub 安装包之间切换时，显示器规则、自动化开关和下载目录等设置可能恢复为默认值的问题。
- 修复重新安装、重新添加目录或媒体库索引缺失后，已有归档图片可能不再显示的问题。
- 修复单个损坏或不匹配的归档影响其他有效图片恢复的问题，并清理已经失效目录对应的可重建索引。

## 下载与安装

- 当前版本使用 ad-hoc 签名且未经过 Apple 公证。首次打开时，可能需要在“系统设置 -> 隐私与安全性”中确认。
